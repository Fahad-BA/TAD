# TAD — TikTok Account Details

واجهة SPA عربية RTL لعرض تفاصيل حسابات TikTok بأسلوب محاكاة تفاعلي، مع دعم نقطة API مخصصة اختيارياً.

Live app: https://tad.fahadhq.poke.site

## تشغيل

```bash
npm install
npm run dev
```

المشروع يستخدم وضع المحاكاة افتراضياً. يمكن إدخال Custom API Endpoint و API Key من الإعدادات المتقدمة لتجربة مصدر بيانات مباشر.
